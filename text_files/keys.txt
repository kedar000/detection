SPECIAL CHARACTERS REFERENCE — MAC & WINDOWS
================================================================================

READ THIS FIRST — a quick correction that makes the rest of this file make sense
--------------------------------------------------------------------------------
- On Mac, the OPTION (⌥) key — NOT Command — is the one that types special
  characters and accents. Option+A produces "å", Option+C produces "ç", etc.
- COMMAND (⌘) is Mac's main shortcut key. Cmd+A means "Select All," Cmd+B means
  "Bold" — it triggers an action, it does not produce a character.
- CONTROL (⌃) on Mac is also mostly used for shortcuts (Control+click =
  right-click). In Terminal / command-line apps, Control+letter sends a
  real "control code" (e.g. Control+C cancels a running command) — that part
  genuinely IS "Control + key produces something," so it's included below.
- FN switches the top row between F1–F12 and media/system functions
  (brightness, volume...), and does things like Fn+Delete = forward delete.
  It does not combine with letters to produce printable characters.
- Windows has no key that behaves like Mac's Option. Instead, Windows types
  special characters with ALT + a number typed on the NUMERIC KEYPAD (hold
  Alt, type the digits, release Alt). That's the closest true equivalent,
  so it's what's listed under "Windows," organized by letter where possible.

1. MAC — OPTION (⌥) KEY + LETTER  →  special character  [US keyboard layout]
================================================================================
Hold Option, press the letter, release both.

  A  ->  å   a with ring above
  B  ->  ∫   integral sign
  C  ->  ç   c with cedilla
  D  ->  ∂   partial differential
  E  ->  ´   acute accent — DEAD KEY: release, then type a vowel -> é, á, í, ó, ú
  F  ->  ƒ   florin / f with hook
  G  ->  ©   copyright sign
  H  ->  ˙   dot above
  I  ->  ˆ   circumflex accent — DEAD KEY: e.g. + e -> ê, + o -> ô
  J  ->  ∆   increment / delta
  K  ->  ˚   ring above
  L  ->  ¬   not sign
  M  ->  µ   micro sign
  N  ->  ˜   small tilde — DEAD KEY: + n -> ñ, + o -> õ, + a -> ã
  O  ->  ø   o with stroke
  P  ->  π   pi
  Q  ->  œ   oe ligature
  R  ->  ®   registered sign
  S  ->  ß   sharp s / eszett
  T  ->  †   dagger
  U  ->  ¨   diaeresis — DEAD KEY: + u -> ü, + o -> ö, + e -> ë
  V  ->  √   square root
  W  ->  ∑   summation
  X  ->  ≈   almost equal to
  Y  ->  ¥   yen sign
  Z  ->  Ω   omega

5. MAC — CONTROL (⌃) KEY
================================================================================
Common Control shortcuts (system-wide):
  Control + click              -> Right-click / contextual menu
  Control + Command + Space    -> Emoji & Symbols viewer (Character Viewer)
  Control + Command + Q        -> Lock screen
  Control + Eject              -> Restart/Sleep/Shut Down dialog

Control + letter in Terminal / text consoles — this is the one place a
modifier key genuinely sends a distinct code per letter (classic ASCII
control codes, still used by bash/zsh, vim, nano, etc.):

  A -> Beginning of line        B -> Back one character
  C -> Interrupt / cancel (^C)  D -> Delete char / end of input (EOF)
  E -> End of line              F -> Forward one character
  G -> Bell                     H -> Backspace
  I -> Tab                      J -> Line feed
  K -> Kill text to end of line L -> Clear screen
  M -> Carriage return / Enter  N -> Next line (history)
  O -> (rarely used)            P -> Previous line (history)
  Q -> Resume output (XON)      R -> Reverse-search history
  S -> Pause output (XOFF)      T -> Transpose characters
  U -> Kill line backward       V -> Insert next character literally
  W -> Delete word backward     X -> Cancel
  Y -> Yank (paste killed text) Z -> Suspend process (^Z)

6. MAC — FN KEY
================================================================================
Fn does not combine with letters to make characters. What it actually does:
  Fn + F1...F12   -> Toggles the top row between brightness/volume/media
                      controls and standard F1–F12 function keys
  Fn + Delete     -> Forward delete (deletes the character ahead of cursor)
  Fn + Up Arrow   -> Page Up
  Fn + Down Arrow -> Page Down
  Fn + Left Arrow -> Home
  Fn + Right Arrow-> End
  Fn (tap, on newer keyboards with a Globe/🌐 key) -> Opens Emoji picker

8. WINDOWS — ALT + NUMPAD CODES FOR COMMON SYMBOLS
================================================================================
These use the leading-zero (Windows-1252 / ANSI) codes — reliable in Word,
browsers, and most modern apps:

  Trademark ™        0153        Copyright ©         0169
  Registered ®       0174        Section §           0167
  Pilcrow ¶          0182        Bullet •            0149
  Degree °           0176        Plus-minus ±        0177
  Euro €             0128        Pound £             0163
  Cent ¢             0162        Yen ¥               0165
  Micro/mu µ         0181        Per mille ‰         0137
  Dagger †           0134        Double dagger ‡     0135
  Ellipsis …         0133        En dash –           0150
  Em dash —          0151        One quarter ¼       0188
  One half ½         0189        Three quarters ¾    0190
  Superscript 2 ²    0178        Superscript 3 ³     0179
  Left guillemet «   0171        Right guillemet »   0187
  Left double quote "  0147      Right double quote "  0148
  Left single quote '  0145      Right single quote '  0146
  Feminine ordinal ª 0170        Masculine ordinal º 0186
  Inverted "!" ¡     0161        Inverted "?" ¿      0191

Math / Greek symbols NOT in the Windows-1252 set above — these use the
older, no-leading-zero DOS/CP437 codes instead (works reliably in Notepad;
support varies in newer apps):

  Division ÷    246       Almost equal ≈   247
  Less/equal ≤  243       Greater/equal ≥  242
  Square root √ 251       Infinity ∞       236
  Omega Ω       234       Pi (lowercase) π 227
  Sigma (cap) Σ 228

Symbols with NO simple Alt+numpad code in either set (∆, ≠, ∫, ∂, ∏, ∑, √,
≈, ∞ as proper Unicode math glyphs) — in Microsoft Word, type the hex code
below then press Alt+X immediately after, and it converts to the symbol:

  Not equal ≠        type 2260 then Alt+X
  Increment ∆        type 2206 then Alt+X
  Integral ∫         type 222B then Alt+X
  Partial ∂          type 2202 then Alt+X
  N-ary product ∏    type 220F then Alt+X
  N-ary summation ∑  type 2211 then Alt+X
  Square root √      type 221A then Alt+X
  Almost equal ≈     type 2248 then Alt+X
  Infinity ∞         type 221E then Alt+X

Outside Word: use Character Map (search "charmap" in the Start menu) to
find and copy any of these instead.

11. NOTES & CAVEATS
================================================================================
- Mac Option/Shift+Option combos above are for the U.S. keyboard layout.
  Other layouts (ABC Extended, International, etc.) place characters
  differently. To see YOUR layout live: System Settings > Keyboard >
  turn on "Show Input menu in menu bar" > menu bar icon > Show Keyboard
  Viewer, then hold Option (and Option+Shift) to watch the keys change.
- Windows Alt+numpad codes need a physical numeric keypad, or NumLock +
  Fn on laptops without one. They don't work over some remote-desktop
  sessions or in a handful of apps (notably some UWP/Store apps).
- Don't mix up the two Windows code pages: codes WITH a leading zero
  (e.g. 0163) use Windows-1252/ANSI; codes WITHOUT one (e.g. 163 alone)
  use the older DOS/CP437 set and can produce a different character.
- On international Windows keyboards (UK, EU, etc.), Ctrl+Alt (or the
  AltGr key) + a letter can also type accented/special characters
  directly (e.g. Ctrl+Alt+E = € on many EU layouts) — this depends on
  the keyboard layout selected and doesn't apply to a standard US layout.
- For anything not covered above: Mac's Character Viewer (Control+
  Command+Space) and Windows' Character Map (charmap.exe) both let you
  search by name and copy any Unicode character.
