Operating System Kernel
        │
Window Manager / Desktop Compositor        (DWM on Windows, WindowServer on macOS,
        │                                   a Wayland/X11 compositor on Linux)
        │   • Owns the full window stack (z-order, bounds, PIDs, titles) for
        │     every application on the machine.
        │   • Produces the final composited framebuffer sent to the display.
        │   • Also produces whatever buffer is handed to "capture" consumers
        │     (screen recorders, video-call apps, getDisplayMedia backends) —
        │     and can selectively omit specific windows from that second
        │     buffer on a per-window, per-app basis (see Section 4).
        ▼
Browser Process (privileged, native code)
        │   • Owns HWNDs/NSWindows for its OWN top-level windows only.
        │   • Can query its own window's OS-level state (focused? minimized?
        │     fullscreen?) but has no standard, supported way to enumerate
        │     *other* applications' windows.
        ▼  ── sandbox / IPC boundary ──
Renderer Process (sandboxed, one per site/tab)
        │   • Deliberately has NO direct OS API access. This is not an
        │     oversight — the renderer sandbox exists specifically so that
        │     a malicious or compromised webpage cannot touch the OS,
        │     the filesystem, or other processes.
        ▼
Layout / Rendering Engine (Blink, Gecko, WebKit) → DOM
        ▼
JavaScript execution environment
        ▼
Web-exposed APIs — a deliberately narrow, curated surface
